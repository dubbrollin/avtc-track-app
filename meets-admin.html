📋 How to upload results & go live

Parents follow each meet on its own results page. While the meet is running, that page updates itself every 30 seconds, so anything you send shows up there within about half a minute.

1Before meet day

  1. Use the timing laptop (the one with Meet Manager) and open this page in Google Chrome or Microsoft Edge.
  2. Sign in with the email you registered with as a timer.
  3. On the meet below, click Download entries (Hy-Tek). In Meet Manager use File › Import › Semi-Colon Delimited Entries and pick that file.
  4. Open the meet in Meet Manager in multi-user mode. In single-user mode Meet Manager locks the meet file and live results can't read it.
  5. Practice once: click Upload results, tick Test only, and connect (step 2). It shows what it reads without posting anything.

2Connect for live results

On meet day, click Upload results on today's meet, then pick one of these:

A. Fully automatic (recommended)

  1. Make sure Meet Manager has the meet open in multi-user mode.
  2. Click the red button Fully automatic: connect to the Meet Manager database.
  3. Pick this meet's .mdb file — for example in C:\tfmeets6 (Meet Manager's File › Open shows where it is).
  4. The first time, open Which event is which and pick an event for any orange row. You only do this once per meet.
  5. That's it. Every result you accept in Meet Manager goes live by itself; the page checks every 30 seconds.

B. One key per event (needs Meet Manager's Pro option)

  1. In Meet Manager: Run › Web › Log-in, tick Do not upload, and make sure F11/F12 are turned on.
  2. Here, click the white button One key per event and pick the C:\Realtime folder.
  3. When an event is finished, open it in Run and press F12. It goes live within seconds.

You'll see ● Connected (or ● Watching) and a list of each event as it's posted. Make sure Test only is not ticked on meet day.

3During the meet

  • Leave this page open the whole meet. You can use Meet Manager in front of it, but don't close the tab.
  • Keep the laptop plugged in and online. If the internet drops, it keeps retrying and catches up when it's back.
  • Fixed a mark in Meet Manager? Just send that event again (or wait for the automatic check). The new results replace the old ones; nothing is ever doubled.
  • Click View on the meet to see exactly what parents see.

4No live connection? Upload a file

  1. In Meet Manager, export the results as a semicolon-delimited file (File › Export).
  2. Here, click Upload results, choose the file under Upload the results file, then Save these results.
  3. Do this every few events, as often as you like. Each upload replaces those events.

5When the meet is over

  • Send the final results one more time (or upload the final file), then click Stop.
  • Check the meet's results page with View.

Something not right?

  • "This browser can't watch files" → open this page in Chrome or Edge on the Windows timing laptop.
  • "Can't read the meet file" / "could not be read" → Meet Manager is in single-user mode. Close the meet and open it again in multi-user mode; the page connects on its next try.
  • "Doesn't look like a Meet Manager database" → you picked the wrong file; pick the meet's .mdb.
  • Field marks look wrong → field marks are read in the unit Meet Manager recorded them in. If one still doesn't match, open Which event is which and set Field marks to always inches or always meters.
  • Still stuck → click Download a database report (no athlete names in it) and send it to your site admin.
  • Posted something by mistake? Ask a team admin to remove it.
